# Banking System

A Java-based banking system using OOP concepts, Maven, JUnit 5, and Docker.

## Features

- Savings Account
- Current Account
- Fixed Deposit Account
- Deposit & Withdraw
- Transfer Funds
- Interest Calculation
- Transaction History
- Unit Testing
- Docker Support

## Technologies Used

- Java 17
- Maven
- JUnit 5
- Docker

## Run Project

mvn clean package

java -jar target/banking-system-1.0.jar
